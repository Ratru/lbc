# PDF Text Editor Bot

Telegram-бот для редактирования текста в PDF-файлах с сохранением форматирования (шрифты, размеры, цвета, позиции).

## Установка

```bash
pip install -r requirements.txt
```

## Настройка

1. Скопируйте `.env.example` в `.env`:
   ```bash
   cp .env.example .env
   ```

2. Получите токен у [@BotFather](https://t.me/BotFather) и вставьте в `.env`:
   ```
   TELEGRAM_BOT_TOKEN=ваш_токен_здесь
   ```

## Запуск

```bash
python bot.py
```

## Использование

1. Откройте бота в Telegram и нажмите `/start`
2. Отправьте PDF-файл
3. Бот покажет список текстовых блоков (по 8 штук на странице)
4. Нажмите на номер блока чтобы отредактировать его текст
5. Введите новый текст — бот сохранит изменение
6. Когда все правки готовы, нажмите **💾 Скачать PDF**
7. Бот вернёт изменённый PDF с сохранёнными шрифтами и форматированием

## Команды

| Команда | Описание |
|---------|----------|
| `/start` | Запустить бота |
| `/cancel` | Сбросить текущую сессию |

## Как работает замена текста

Для каждого изменённого блока бот:
1. Извлекает метаданные блока: шрифт, размер, цвет, координаты bbox
2. Добавляет аннотацию redact поверх старого текста
3. Применяет все redact-аннотации для страницы
4. Вставляет новый текст на то же место с теми же параметрами

Если встроенный шрифт недоступен, используется похожий стандартный шрифт (Helvetica / Times-Roman).
